## 3. Instrucción dominante de stall y diagnóstico

Las `21` muestras propias en TSV están fragmentadas a lo largo de múltiples repeticiones inlined del **mismo patrón de bucle de acumulación de modificadores** (`[0x0125A5B8] - [0x0125A5B4]`, stride `8` bytes por slot de modificador, solo suma los 32 bits bajos `[ecx + edx*8]`) `[confirmed]`:

- **Muestras en bucles `add [dst + edx*8], src[edx*8]` (`16 / 21` = `76.2%` de own)** `[confirmed]`:
  - `0x005105EF` (`4` muestras): `01 0c d0` `add dword ptr [eax + edx*8], ecx` (bucle `0x005105E2..0x005105FC`)
  - `0x0051040F` (`2` muestras): `01 0c d0` `add dword ptr [eax + edx*8], ecx` (bucle `0x00510400..0x0051041C`, lectura `[eax+0x540]`)
  - `0x0050F310` (`2` muestras): `01 0c d0` `add dword ptr [eax + edx*8], ecx` (bucle `0x0050F303..0x0050F31D`)
  - `0x0050F03D` (`2` muestras) + `0x0050F03A` (`1` muestra): `mov ecx, [ecx+edx*8]; add [eax+edx*8], ecx` (bucle `0x0050F030..0x0050F04A`)
  - `0x00510F45` (`2` muestras): `01 30` `add dword ptr [eax], esi` (bucle `0x00510F30..0x00510F4E`, stride `8`)
  - `0x005102C9` (`1` muestra): `lea edi, [eax*8]` antes de `add [eax+edi], edx` (bucle `0x005102C3..0x005102E1`)
  - `0x00510D64` (`1` muestra): `01 10` `add dword ptr [eax], edx` (bucle `0x00510D4E..0x00510D6B`, stride `8`)
  - `0x005105FA` (`1` muestra): `cmp edx, esi` (cierre de bucle `0x005105E2..0x005105FC`)
- **Resto (`5 / 21` = `23.8%`)** `[confirmed]`: `0x0050EE6D` (`1`), `0x0050EE70` (`1`), `0x0050EDE5` (`1`, carga slot `[eax+0x20]` para virtual call), `0x0050EF5D` (`1`), `0x0050F38C` (`1`).

- **Diagnóstico (`[confirmed]` / `[inferred]`)**: **Mixto compute/memory-stride (anti-patrón de código inlined y stride de `8 B`)**:
  1. El compilador inlined ~10–15+ copias separadas de `AddModifier(country_mods, src_mods)` (hay `47` lecturas de `[0x0125A5B8]` en `9941 B` de código), inflando I-cache y manteniendo bucles escalares de 1 elemento por iteración sin SIMD `[confirmed]` / `[inferred]`.
  2. Además, en cada iteración se suman elementos con **stride de `8` bytes** (solo modificando el dword bajo, desperdiciando 50% de ancho de línea de caché y duplicando los misses de caché al leer `src->+0x18` de cada edificio/tecnología/issue/política) y dejando código redundante (`lea esi, [edx*8]` muerto) `[confirmed]` / `[inferred]`.

## 4. Cota de Amdahl, overhead de hook y cross-reference con `Country_PrePass`

- **Cota superior de Amdahl**: **`1.60%` own / `2.06%` inclusive** (`21` / `27` de `1311` muestras; `8.75` / `11.25 ms/day` TSV).
- **Overhead de hook**: despreciable por llamada (`~1` vez/país/día), pero el costo de ingeniería/riesgo de reescribir `9941 B` (`47` news, `12` deletes, `4` globals, `2` virtual calls, RNG indirecto en `0x009747A0`) es altísimo para un techo máximo de `2.06%` `[confirmed]` / `[inferred]`.
