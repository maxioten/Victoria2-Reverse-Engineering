## 5. Cota de Amdahl y análisis de overhead de hook (`confirmed` / `inferred`)

- **Techo de Amdahl (`confirmed`)**: **`2.21%` hoja / `3.43%` inclusivo** en `performance_patch_samples.tsv` (`~2.0%` own en TGC 1836).
- **Overhead de hook (`confirmed`)**: Despreciable (se llama como máximo una vez por país de IA por día, función de `1195` B con `__thiscall` estándar).
- **Por qué no basta recompilar (`confirmed` / `inferred`)**: Recompilar `0x0084B0F0` en C manteniendo el mismo acceso `self->relations[other_idx]->+0x34` seguirá pagando exactamente los mismos misses de caché en `0x0084B299`/`0x0084B29D`.
- **Alternativas de patrón**:
  1. **Software prefetching** (`_mm_prefetch`) de `self->relations[other_idx + k]` (y `countries[i + k]`) dentro del bucle `0x0084B270..0x0084B417` (nota: `performance_patch.ini` incluye la clave `prefetch_ai_relations = 0`, inactiva en el perfil base).
  2. **Poda de tags inactivos + bitset/tabla compacta de `rel+0x34 != 0`**: No se pueden saltar tags sin provincias a ciegas porque `0x0084B299` añade cualquier tag con `rel+0x34 != 0` y también revisa `'REB'` (`0x0084B29F..0x0084B2C6`); sí se pueden saltar si un bitset compacto por país garantiza `rel+0x34 == 0` y `other_tag != 'REB'`.
